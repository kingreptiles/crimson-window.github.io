# Crimson Window — public website

Static GitHub Pages site for the Crimson Window app, which is **in development**. No public download or purchase is available.

## Pages
- `index.html`: overview and verified development features
- `guide.html`: current app workflows
- `community.html`: age access, sharing, reporting, and moderation
- `support.html`: availability, FAQ, and contact
- `privacy.html`: website privacy and development data-flow notes
- `terms.html`: brief website/development terms

Shared styling is in `site.css`; the favicon is local SVG. No build step, third-party scripts, analytics, external fonts, or package dependencies are required. All navigation uses relative paths so the site works under a GitHub Pages project path.
