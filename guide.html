Start with your role

A character describes the AI’s role. A profile describes yours. A persona guides how the character behaves. Custom instructions add your own directions for the conversation.

  1. Choose or create a profile for the person you want to play.
  2. Find a character in the Library or create one of your own.
  3. Choose the character’s persona and an available AI package.
  4. Review your custom instructions, then start the conversation.

Keep the controls close

Buttons above the chat input let you switch your profile, AI package, persona, and custom instructions. The selected names stay visible, so you can see what is shaping the current conversation.

In a development build, Account → Profiles contains your profiles. Account → Creations contains characters, personas, and custom instructions.

Write your own directions

Create reusable instruction cards and select one for your chats. Use {user} for the current profile name and {character} for the AI character name. These placeholders are replaced when a response is requested.

Example instruction

Let {user} control their own actions and dialogue. Respond only as {character}.

Use the pencil beside a field to edit an existing card. Instructions are guidance, not a guarantee that a model will always follow them.

Give a story continuity

Pin messages to keep key details available, and use manual or automatic summaries to carry a longer story forward. Summaries are AI-generated and can miss details, so review important continuity.

Alternative responses let you try a different reply. Checkpoints let you return to an earlier point. Continue in silence asks the character to continue without a written user reply; a visible silence bubble marks that moment.

Silence markers are omitted from summary text and do not count toward summary progress. They remain available as context for the next AI response.

Create and manage memories

  1. Open Account → Memories → Create memory.
  2. Choose a conversation with a public or built-in character.
  3. Enter a title, select messages, and use the pencil to edit the copy you will share.
  4. Choose Publish memory.

Your posts are grouped by character in Memories. Use Edit to change the title, text, or selected messages, and Delete to remove a post. The original conversation stays unchanged.

Shared memories are visible to other users who can access the character. Title-only changes preserve reactions; changing the messages resets reactions. Review the text for personal information before publishing.

Choose how AI responds

Available AI packages and models depend on the current service configuration and your account’s access. A package may try another supported model when an earlier attempt fails.

Current builds support a user-owned OpenAI API key and model selection. This is separate from a ChatGPT subscription. The key is stored using device-provided protected storage and is sent through the Crimson Window backend when needed to make a provider request.

Provider charges, availability, and policies apply to your API account. Do not share your key or put it in a character, instruction card, memory, or support message. Chats require an online AI service; local storage does not mean local AI inference.
