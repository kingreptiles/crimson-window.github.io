Before you write

A few useful answers.

Where can I download the app?

You cannot download it publicly yet. Availability information will be added here when there is a public release.

Is Crimson Window still adults-only?

The current app rule is 16+ for accounts. Mature content is restricted to adults aged 18+ and controlled through content preferences. Users aged 16–17 cannot enable it.

How do I create or edit a shared memory?

In a development build, open Account → Memories → Create memory and choose a conversation. Use Edit or Delete beside your posted memories. See the memory guide for the full flow.

Why does a character forget details or ignore instructions?

AI replies depend on the selected model, the recent conversation, summaries, and pinned information. Models can make mistakes. Check the selected profile, persona, instructions, and summary before trying another package or response.

Is a user-owned API connection included with ChatGPT?

No. OpenAI API access and billing are separate from a ChatGPT subscription. Your API provider’s charges, model access, and policies apply. Never email an API key or password.

What should I include in a bug report?

Include your platform, app/build version, what you expected, what happened, and short steps to reproduce it. Add a request reference if the app shows one. Redact private text from screenshots and never send passwords, payment-card details, or API keys.

How do I report content or ask about privacy?

Use Report character in the app, or email uta.cornelc@gmail.com with the relevant content location and a short explanation. For a privacy question, describe the data and feature involved. Do not send illegal material or unnecessary personal information.

Where are prices and subscription options?

No public purchase is offered here while the app is in development. Development builds may display account tiers and usage information. Final plans, prices, and purchase terms will be provided with any public paid offering.
